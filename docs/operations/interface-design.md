# Mansora interface direction

Owner-approved on 2026-11-11: Xero + Linear + Stripe, with gentle glow and appealing, clean styling. Mansora remains the SaaS provider; each client sees its own business workspace.

- [Xero dashboard](https://www.xero.com/ae/accounting-software/dashboard/): clear financial summaries, readable tables and contextual actions.
- [Linear design refresh](https://linear.app/now/behind-the-latest-design-refresh): restrained navigation, consistent spacing and focused working areas.
- [Stripe dashboard](https://docs.stripe.com/dashboard/basics): precise statuses, calm surfaces and clear operational hierarchy.

These are interaction and presentation references, not imported assets or copied branding. Mansora purple and gold remain the identity. Shared `packages/ui/src/polish.css` supplies neutral surfaces, subtle static background glow, soft card depth, visible focus and consistent controls for both business and operator interfaces. Reduced-motion, forced-colour and print treatments remain available.

Daily shortcuts stay visible; secondary tools and detailed summaries open on demand. Dashboard refresh reloads actual records, including changes made in another session. Search reveals the selected navigation group before the page is painted. Browser sign-in and report copy no longer promise desktop-only offline behaviour.

Financial calculations, discounts, permissions, billing providers and stored records are unchanged by this visual work. End-to-end acceptance exercises their real implementations; see the task-board handoff for exact validation results.
