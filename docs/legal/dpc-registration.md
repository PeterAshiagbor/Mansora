# Registering with the Data Protection Commission

Act 843 requires a data controller to register with the Data Protection Commission (DPC) before processing personal data,
and to renew the registration when due. Processing without registration is an offence. Check the DPC's current forms,
fees, size bands and renewal period on its website before applying; they change.

## Mansora

Mansora is a controller for its own records (clients, owners, administrators, billing) and a processor for shop data.

Checklist:
- [ ] Company registration certificate and TIN ready.
- [ ] Name the data protection supervisor (and arrange the DPC's training if required).
- [ ] Describe processing: purposes and data groups from [mansora-privacy-notice.md](mansora-privacy-notice.md); data held for
      shops as processor from [data-processing-agreement.md](data-processing-agreement.md).
- [ ] State that data is stored outside Ghana (United States, Railway), with the safeguards.
- [ ] Describe security measures (section 5 of the data processing agreement).
- [ ] Apply on the DPC portal, pay the fee, keep the certificate and registration number.
- [ ] Put the registration number in the privacy notice, terms and website.
- [ ] Diary the renewal date.

## Each shop (client)

Each shop that keeps customer or staff data is a controller and should register. Mansora's part:
- [ ] Add a short note to the onboarding pack (`docs/onboarding/client-handover.md`): what registration is, why, and the DPC link.
- [ ] Give the shop the filled-in notices: customer notice ([privacy-notice.md](privacy-notice.md)) and staff notice ([staff-notice.md](staff-notice.md)).
- [ ] Give the shop the list of what Mansora stores and where, for its application (from the data processing agreement).
- [ ] Ask the lawyer whether very small sole traders are exempt or in a lower fee band.

Mansora should not register on a shop's behalf unless the shop asks in writing and the DPC allows it.
